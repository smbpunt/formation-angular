Démo track

Tape quelque chose dans les inputs, puis clique sur le bouton.
Si l'input garde sa valeur → le nœud DOM a été réutilisé.
Si l'input est vide → le nœud DOM a été recréé.

✅ track user.id

Chaque utilisateur est identifié par son id.

    @for (user of users(); track user.id) {
  • {{ user.name }}
    • }

❌ track $index

Chaque position est identifiée par son index.

    @for (user of users(); track $index) {
  • {{ user.name }}
    • }

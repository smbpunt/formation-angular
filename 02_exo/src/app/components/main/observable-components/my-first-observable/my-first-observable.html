Mon Premier Observable

Un Observable est un flux de données asynchrone.
Il ne fait rien tant qu'on ne s'y abonne pas.
Ici, interval(1000) émet un entier toutes les secondes.

Approche 1 — toSignal()

Convertit l'Observable en Signal. On l'appelle comme une fonction : timerSignal().

{{ timerSignal() }}

Approche 2 — pipe async

S'abonne directement dans le template. Affiche null avant le premier emit.

{{ timer$ | async }}

Ouvre la console pour voir les logs de l'abonnement manuel.

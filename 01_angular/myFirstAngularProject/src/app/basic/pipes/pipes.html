Les pipes Angular

1- Pipes sur les chaines

Donnée brute : {{ nom }}

uppercase {{ nom | uppercase }} Tout en majuscule
lowercase {{ nom | lowercase }} Tout en minuscule
titlecase {{ nom | titlecase }} Première lettre de chaque mot en majuscule

2- Pipes sur les nombres

Donnée brute : {{ price }}et {{ percent }} (%)

number {{ price | number }} Par défaut
number:'1.2-2' {{ price | number:'1.2-2' }} 1 entier min., 2 décimales min/max
currency:'EUR' {{ price | currency:'EUR' }} Devise
currency:'USD':'symbol':'1.0-0' {{ price | currency:'USD':'symbol':'1.0-0' }} Dollar sans décimale
percent {{ percent | percent }} Pourcentage sans décimale
percent:'1.1-2' {{ percent | percent:'1.1-2' }} Pourcentage 1 entier min, 1-2 (min-max) décimales
